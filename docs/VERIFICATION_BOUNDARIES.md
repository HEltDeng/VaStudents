# 身份、材料与权益边界

访客始终可浏览公开优惠，第三方官方领取直接跳转其来源，不以 VaStudents 登录认证设置额外门槛，也不假装本应用认证能替代官方资格规则。

App开发链路：首次说明→公开首页/钱包→原意图("wallet"或"qr")→明确测试账户→虚构学校绑定→生成固定合成文本→私有目录保存→pending→测试批准/拒绝→重提、到期、撤销→返回钱包/测试二维码。测试码有到期时间和测试URI，不包含姓名/学号/原件。没有服务端验签或商家接受，不具防复制、身份认证或消费价值。

preview 构建 DEVELOPMENT_FEATURES=false；开发入口方法独立检查常量并抛SecurityException。dev 使用不同包名，不能将其本地审批状态混入 preview。真实核销数量始终为0；登录、资格、权益、核销事实分别处理。身份码和核销演示码用途不同。

App合成材料位于 getNoBackupFilesDir，禁止系统备份，到期设为7天，在到期后的下一次启动清除（未启动时仍可能留存）；用户可立即清除。未提供任意文件选择器，不读取用户真实学信网文件。服务端领域原型有可配置保留时间和访问时/维护删除，角色/owner校验、幂等与生产硬禁用测试入口；尚未部署或接入Android，因此不能称为可信生产审核服务。

真实材料收集前，必须确认数据范围（最低需要证明什么）、审核主体与人员、原件保留及删除期限；再实现真实身份认证、受控私有加密存储、上传鉴权/大小类型扫描、短期访问授权、审计持久化和删除调度。不会默认永久存储。本人身份/在读资格/材料真实性分别记录，不宣称有学信网API或自动权威核验。

真实账户登录、手机号/邮箱绑定、上传传输、后台人工审核、服务端QR签发/撤销、商户验签、真实权益和核销仍待独立服务与合作授权；当前仅为可检验的开发流程和服务端边界原型。
