# VaStudents 验证领域与私有材料存储原型

这是 **未部署、未接入 App 的 Python 标准库领域原型**，不是生产认证服务、学信网接口、权威学生认证或商户核销服务。没有监听网络、注册账户、读取用户文件或真实材料。所有演示审批始终带 `synthetic=True`；不能转成商户接受的资格或核销码。

## 已实现

- 服务使用服务端 session 解析身份和角色；学生只能读取自己的记录和材料。审核者与学生分离，拒绝本人审核。
- 状态：`pending` → `approved` / `rejected`；等待中或已通过可 `expired` / `revoked`。终态不可重新批准。`identity`、`enrollment`、`authenticity` 分别保存结论；三项测试结论通过才允许演示批准。
- 接收入口只选择两个内置固定合成文本 fixture，不接受任意文件/字节，不提供文件选择或学信网材料上传。
- `MaterialStore` 抽象与本地实现：随机文件 ID、无原始文件名、所有者授权、摘要完整性校验、路径穿越拒绝。材料最迟保留 30 天，默认 7 天；资格有效期独立。撤销立即删除；到期访问和维护任务触发删除。
- 上传、审核与撤销有请求幂等性；同一 key 不同内容拒绝，重放旧批准不会恢复已撤销资格。
- 审计仅存事件、随机记录 ID、状态和合成标记；不记录 session、主体、材料路径、原始内容或自由文本。
- `PRODUCTION` 模式硬拒开发登录、跳过、合成材料提交、演示审批/撤销，并拒绝开发认证提供者。移动端 flag 不能开启真实材料入口。即使配置真实认证适配器与已确认的数据政策，真实材料接收也明确返回 `real_intake_not_implemented`。

## 运行

需要 Python 3.11+，无第三方依赖：

```powershell
Set-Location <独立项目路径>\verification_backend
python -m unittest -v
```

测试在系统临时目录创建明确合成材料，完成后自动清除。不会生成 JKS、密码或其他凭据。

## 部署前仍需完成

本原型的记录、session、幂等表和审计只在内存，**没有持久化事务、并发隔离或服务器调度器**。不应直接用于多进程服务。材料目录不能放进 Git、APK、静态资源或公开 Web 根目录。测试使用临时目录；尚无真实收集用的持久材料目录。

POSIX 上创建目录 `0700`、文件 `0600`；Windows 上 Python 文件模式不能保证私有 ACL。正式本地存储必须以专用服务身份配置并验证 NTFS ACL，或使用具有服务身份访问控制的私有对象存储；当前没有证明 Windows 持久存储的访问隔离。删除是逻辑文件删除，不承诺 SSD、安全擦除或备份清除；生产需明确备份生命周期和密钥销毁策略。

上线前必须先由用户确认：收集字段/材料范围、审核组织与授权人员、原件保留和删除期限。随后实现真实认证提供者、私有加密存储、审计持久化、病毒与类型检查、上传限额、传输安全、删除调度及删除失败告警。认证材料不可写入日志、Git、APK 或聊天。必须定义本人/在读/材料真实性结论的审核依据，不能暗示学信网自动核验已存在。

资格记录、将来的权益规则与商户核销记录必须保持独立；本原型没有创建任何商户权益或真实核销记录。
